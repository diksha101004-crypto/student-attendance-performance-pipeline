The main goal of this project is to collect student data from CSV files, clean and transform the data, store it in a database, perform SQL analysis, and display the results using an interactive dashboard.
Technologies Used
Python – Used to build the data pipeline.
Pandas – Used for data cleaning and transformation.
SQLite – Used to store the processed data.
SQL – Used to analyze student performance.
Streamlit – Used to create the interactive dashboard.
Git & GitHub – Used for version control and project hosting.

Future Improvements
Some possible improvements for the project are:
Add more student records.
Connect the pipeline to a larger database.
Automate the data pipeline.
Add more interactive filters to the dashboard.
Add a Power BI dashboard.
Schedule the pipeline to run automatically.

Conclusion
This project demonstrates a basic end-to-end data engineering workflow. It covers data extraction, cleaning, transformation, database loading, SQL analysis, and dashboard visualization using simple and commonly used tools.
